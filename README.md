# Daspro Jobsheet 8 — Perulangan For untuk Pola dan Bentuk

Program latihan **perulangan `for` bersarang** untuk mencetak pola
karakter, bentuk geometris, dan menghitung rata-rata nilai.

## Daftar Program

| Program | Deskripsi |
|---------|-----------|
| `Star13.java` | Pola bintang segitiga |
| `Triangle13.java` | Pola segitiga angka |
| `Square13.java` | Pola persegi |
| `LoveShape13.java` / `LoveShape.java` | Pola bentuk hati |
| `RataNilai13.java` | Perhitungan rata-rata nilai |
| `tugas1.java`, `tugas2.java` | Tugas jobsheet |

## Cara Menjalankan

```bash
javac Star13.java
java Star13
```

## Konteks

Jobsheet 8 Dasar Pemrograman, Politeknik Negeri Malang (Polinema).
